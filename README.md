# Resident Evil 4 Mobile - J2ME Fan Edition

Fan game para Java/J2ME inspirado en el survival horror clasico para telefonos antiguos y emuladores J2ME.

Este proyecto adapta una experiencia de accion y horror en formato movil, con escenarios modificados, textos en espanol e ingles, musica en bucle, tienda, niveles ajustados y jefe final.

## Descarga

La version jugable se publica como archivo `.jar` en la seccion **Releases** del repositorio.

Archivo recomendado:

- `RE4_J2ME_CANDIDATO_FINAL_BETA.jar`

## Como jugar

Puedes ejecutarlo en:

- Telefonos compatibles con Java/J2ME.
- J2ME Loader en Android.
- FreeJ2ME / FreeJ2ME-Plus en PC o sistemas retro.
- Emuladores J2ME compatibles con archivos `.jar`.

## Estado

Version candidata final beta.

Incluye:

- Menu principal personalizado.
- Textos argumentales ajustados.
- Musica de menu y eventos.
- Tienda funcional.
- Progresion de niveles.
- Jefe final y escena de cierre.
